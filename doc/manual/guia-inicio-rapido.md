# Guía de Inicio Rápido - GYMETRA

## Para Clientes

### Primeros Pasos

1. **Descarga o accede a la aplicación**
   - App móvil: Disponible en tu tienda de aplicaciones
   - Web: Accede desde tu navegador

2. **Crea tu cuenta**
   - Registra tus datos personales
   - Verifica tu correo electrónico

3. **Obtén tu membresía**
   - Contacta al administrador del gimnasio
   - O selecciona un plan en la aplicación

4. **Accede al gimnasio**
   - Abre la aplicación
   - Ve a "Mi QR"
   - Muestra el código al lector en la entrada

### Funciones Principales

- ✅ Ver tu membresía y fechas
- ✅ Generar código QR para acceso
- ✅ Consultar historial de accesos
- ✅ Actualizar tu perfil

## Para Administradores

### Acceso al Panel

1. Accede a: `http://localhost:8101`
2. Inicia sesión con tus credenciales de administrador

### Tareas Comunes

**Gestionar Usuarios**
- Ver lista → "Usuarios"
- Crear nuevo → "Usuarios" → "Nuevo"

**Gestionar Membresías**
- Ver todas → "Membresías"
- Asignar nueva → "Membresías" → "Nueva"

**Ver Reportes**
- Ingresos → "Reportes" → "Ingresos"
- Asistencia → "Reportes" → "Asistencia"

### Flujo Rápido: Asignar Membresía

1. Ve a "Membresías" → "Nueva"
2. Selecciona el usuario
3. Selecciona el plan
4. Confirma
