# Manuales de Usuario - GYMETRA

Esta carpeta contiene los manuales de usuario del sistema GYMETRA, dirigidos a diferentes tipos de usuarios del sistema.

## Estructura de Manuales

### 📱 Manual de Usuario (Cliente)
**Archivo**: `manual-usuario-cliente.md`

Guía completa para los clientes del gimnasio que usan la aplicación móvil/web. Incluye:
- Registro e inicio de sesión
- Visualización de membresía
- Uso del código QR para acceso
- Consulta de historial de accesos
- Actualización de perfil

### 👨‍💼 Manual de Administrador
**Archivo**: `manual-administrador.md`

Guía para administradores del sistema que gestionan el gimnasio. Incluye:
- Gestión de usuarios
- Creación y gestión de planes de membresía
- Asignación de membresías
- Procesamiento de pagos
- Generación de reportes
- Gestión de sucursales

### 🚀 Guía de Inicio Rápido
**Archivo**: `guia-inicio-rapido.md`

Guía rápida para empezar a usar el sistema, tanto para clientes como administradores.

### ❓ Preguntas Frecuentes (FAQ)
**Archivo**: `faq.md`

Preguntas frecuentes y respuestas comunes sobre el uso del sistema.

## Presentación del Proyecto

La carpeta `Presentacion GYMETRA/` contiene la presentación HTML del proyecto con diagramas, historias de usuario y planificación.

## Cómo Usar Estos Manuales

1. **Para Clientes**: Comienza con `guia-inicio-rapido.md` y luego consulta `manual-usuario-cliente.md` para detalles específicos.

2. **Para Administradores**: Revisa `manual-administrador.md` para todas las funcionalidades administrativas.

3. **Soporte**: Si tienes dudas, consulta `faq.md` o contacta al equipo de soporte.
